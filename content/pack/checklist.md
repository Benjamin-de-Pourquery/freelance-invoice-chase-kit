# Checklist avant d'envoyer une relance

## Preuves & dossier
- [ ] Facture PDF originale accessible
- [ ] CGV / conditions de paiement (délai, pénalités, indemnité forfaitaire)
- [ ] Preuve d'envoi / de livraison / d'acceptation du devis
- [ ] Historique des échanges déjà faits (dates)

## Timing
- [ ] Date d'échéance dépassée (ou J+ rappel contractuel)
- [ ] Aucun litige qualité/scope ouvert non traité
- [ ] Pas de promesse de paiement encore dans les délais

## Message
- [ ] Une seule facture (ou liste claire) par message
- [ ] Un seul CTA : payer / confirmer une date / forwarder à la compta
- [ ] Ton adapté au niveau (doux → ferme → formel)
- [ ] Lien de paiement / IBAN rappelé
- [ ] Coordonnées + SIRET si mise en demeure

## Canal
- [ ] Email en premier (trace écrite)
- [ ] WhatsApp/SMS seulement si relation déjà établie
- [ ] Mettre en copie la compta si connu

## Suivi
- [ ] Ligne créée / mise à jour dans le tracker CSV
- [ ] `prochaine_action` + `date_prochaine_action` renseignées
